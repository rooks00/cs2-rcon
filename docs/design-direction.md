# Relay interface direction

The generated connection and dashboard references establish a graphite CS2 control desk with warm sandstone artwork. The first screen is the connection workspace, not an obstructing modal.

- Palette: canvas #111315, sidebar #141618, surface #191c1f, stroke #2b2e32, foreground #f1f2f3, action #ff884c. Green is reserved for verified or explicitly demo connection states.
- Typography: locally served Barlow for the distinctive compact grotesk in the references, with system monospace only for commands and protocol values. Page headings 36–42px, section headings 18–22px, body 14–15px, secondary text at least 12px.
- Geometry: 220px rail, 64px topbar, 32–40px main gutters, 24px section gaps. The connection form is about 400px wide, with a large, clear art area beside it. Fields are 44px tall; primary controls 46px. On small laptops the title, inputs, and connect action remain visible; artwork moves below the form on mobile.
- Four identifying components: quiet navigation rail, split connection/architectural scene, flat metric band, terminal and command reference workspace.
- Motion cues: brief cinematic entrance and responsive control transitions. Respect reduced motion; no continuous floating or fake activity.
- Dashboard: broad scene plus actual server identity, four metrics, readable roster and match controls. Keep the generated visual hierarchy while omitting invented tickrate, location, uptime, and score data not exposed by the current implementation.
- Asset: public/images/desert-diorama.webp, created with the built-in image generation tool. This is decorative CS2-inspired artwork, not an accurate map preview.

The image references use some small text and invented operational values. Implementation preserves their composition and material palette while improving readability and keeping displayed telemetry truthful.
